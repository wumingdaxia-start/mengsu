<h1 align="center">花屿星 · Huayuxing</h1>
<p align="center">把身体、睡眠与心情，轻轻记在这里。</p>
<p align="center">日常安康 · 梦境与睡眠 · 心绪陪伴</p>

---

花屿星把日常健康、梦境与睡眠、心情记录连接在一起。你可以在花屿照顾身体，在鱼庭留下梦与夜晚的片段，在星栈整理此刻的感受。三个空间共用一个账号，可以从登录页注册自己的账号，再按需要进入不同空间。记录不必完整，练习也可以随时停下。

## ✨ 功能入口

### 花屿 · 安康守护

| 模块 | 可以做什么 |
| --- | --- |
| 🏡 健康总览 | 查看记录入口，通过数字人身体部位标记关注，录入健康日志 |
| 👤 个人档案 | 记录基本信息、身高体重、生活目标、饮食限制和紧急联系人 |
| 🚶 日常锻炼 | 记录活动，查看近七天活动预览与运动概览 |
| 🥗 饮食健康 | 记录饮食、饮水与餐后感受，回看本周饮食印记 |
| 🌙 睡眠监测 | 记录睡眠和梦境，通过星云滑条记录主观感受 |
| 👁️ 视力检测 | 手动保存专业检查结果，便于后续回看 |
| 🌱 健康挑战赛 | 使用打卡清单记录生活习惯，按自己的节奏回顾 |
| 🫧 安全健康分析 | 汇总睡眠、饮食、活动与情绪记录，查看七日综合预览和打卡提醒 |
| 💬 AI 健康问诊 | 围绕健康记录进行 AI 交流，需配置模型及对应服务 |

记录和汇总用于自我观察，不提供疾病诊断，也不以主观滑条生成健康评分。视力页面用于记录检查结果，并非屏幕视力检查工具。

### 鱼庭 · 梦境与睡眠

| 模块 | 可以做什么 |
| --- | --- |
| 梦境总览 | 浏览梦境示例与场景卡片，进入梦境地图和丝线网络，留下自己的场景感受 |
| 记梦与梦库 | 记录梦境片段、标签与感受，浏览示例和个人快照，按日期、关键词和类型查找；对自己的梦库提问并查看引用记录 |
| 漂流瓶 | 在心事、遗憾、梦想、孤独、快乐和晚安六种入口中安放心情 |
| 梦境创作社区 | 使用「梦境绘图」创作画面，在「查看素材」中选择、查看或删除已保存素材 |
| 梦境内核测试 | 通过12道设问观察八种梦境氛围，查看主副核与八维图，保存报告或生成分享图 |
| 睡眠日记 | 记录上床、入睡、醒来和起床时间，选择夜晚感受；回看近七晚与本月记录，查看上一次记录时间 |
| 睡眠计划 | 设置作息目标，查看睡前流程，按当下状态进入睡前放松练习 |
| 星夜叙语 | 浏览睡前故事、随机换一篇、生成与收藏故事；选择三种陪伴语气、柔和女声或柔和男声，以及五种背景音乐 |
| 安心小工具 | 安放情绪、身体放松、自我肯定、感官练习与睡前三步，按需要切换或结束 |
| 我的空间 | 管理、锁定和导出当前账号的快照，调整体验偏好 |

### 星栈 · 心灵空间

| 模块 | 可以做什么 |
| --- | --- |
| 心理总览与心情记录 | 留下当下心情、生活事件和文字，查看自己的记录 |
| 心绪活动 | 人格、塔罗与三观测试，保存本次探索结果；娱乐内容不作预测或诊断 |
| 呼吸练习与情绪回顾 | 跟随舒适的呼吸提示，回看自己记录的情绪变化 |

AI 绘图、故事生成和梦库问答需要运营者配置服务端模型。人物朗读由网站统一提供柔和男女声，访客无需填写语音 API，也不依赖电脑预装的系统音色；语音生成需要网站服务器联网，网络或上游服务异常时可能暂时无法播放。背景音乐可以独立播放和调节音量。

睡眠数据来自手动记录，不是设备自动监测。梦库问答读取当前登录账号保存的梦境记录，并展示引用片段。测试结果用于个人观察与娱乐，不具备医疗、心理诊疗、解梦占卜功能。示例素材与个人记录区分展示。

## 🌸 三种动态入口

| 场景 | 视觉 | 登录后的入口 |
| --- | --- | --- |
| 花屿 | 柔光水纹与花瓣 | 安全健康空间 |
| 鱼庭 | 游动鱼群与指针互动 | 梦境与睡眠空间 |
| 星栈 | 星光与缓慢流动的星云 | 心理空间 |

各工作区复用对应场景作为低透明度动态背景，并保留清晰的内容阅读层。

## 🧩 技术栈

- **前端：** Vue 3、TypeScript、Vite、Tailwind CSS。
- **交互：** Three.js、GSAP；星云滑条通过 React 桥接使用 Radix Slider 与 Framer Motion。
- **后端：** Python、FastAPI、SQLite。
- **模型：** 千问 OpenAI 兼容接口；心潮和记忆服务为可选外部依赖。

## 🚀 下载后快速启动

只需先安装 **Python 3.12（最低 3.10，安装时勾选 Add Python to PATH）** 和 **Node.js 当前 LTS（最低 22.12，包含 npm）**。无需 Conda、Docker 或单独安装 MySQL。

1. 下载或克隆整个仓库并解压，进入项目根目录。
2. Windows 双击 `start.cmd`；macOS / Linux 在终端运行 `sh start.sh`（Linux 需安装发行版的 `python3-venv` 包）。
3. 首次启动自动创建 `.venv`、下载依赖并构建页面，需要联网。成功后自动打开 [花屿星入口](http://127.0.0.1:8000/entry)。保留启动窗口，再次运行会复用已安装依赖。

首次启动的全新本地安装会创建演示账号：**`demo` / `MengsuDemo2026!`**。三个空间共用这个账号。演示账号是公开的，仅供体验。创建独立账号可在登录页点击「还没有账号？注册账号」，也可以使用命令行：

```powershell
# 在项目根目录运行，按提示输入账号和密码（密码不显示）
python scripts/launch.py --create-account
```

macOS / Linux 把上述 `python` 换成 `python3`。可先完成依赖安装而不启动：`python scripts/launch.py --setup-only`。

日常记录、健康档案和心理测试保存开箱可用。数据保存在本地 `data/`；重新启动仍可读取，退出账号保留数据。AI 对话/生成需自行配置千问密钥；网站人物朗读与天气需要网络；长期记忆、心潮为可选外部服务。未配置的功能会提示不可用，不阻止基础页面和记录功能。

停止时在启动窗口按 Ctrl+C，或 Windows 双击 `stop.cmd`。端口 8000 / 3001 被占用会明确报错，先停止旧服务再启动。安装失败时保留错误信息并重试；若提示缺少 Python / npm，安装后重新打开终端。

### 可选配置与开发

复制 `private/.env.example` 为 `private/.env`，填写自己需要的 AI / MySQL 配置；没有密钥也能启动。MySQL 的已有数据不会自动迁移到本地文件，详见 [工作区与存储说明](LOCAL-WORKSPACES.md)。

前端开发：先启动项目，再在 `frontend/` 运行 `npm run dev`。仅运行前端不能保存数据。修改后运行 `npm run build`；也可重新执行启动脚本自动构建。

对外分享请发送 Git 仓库源码，排除 `.venv/`、`node_modules/`、`data/` 和 `private/.env`；不要发送个人账号、数据库和密钥。对方需运行启动脚本，直接双击 HTML 不会启动后端。

## 🔐 数据与登录方式

- 三个空间共用账号服务的 HttpOnly 会话。健康档案和心理测试按账号分别保存；花屿星原有 SQLite 接口仍面向单机使用，不能据此视为完整的多人托管系统。
- 健康档案、运动饮食睡眠和心理测试默认保存到 `data/safety/`；部分界面偏好仍保存在浏览器中。换电脑不会自动带上本机数据。
- 后端记录使用本地 SQLite，默认数据库为 `data/mengsu.db`；媒体和导出文件保存在 `data/`。
- AI 对话、绘图和文字生成依赖有效模型配置；网站统一人物朗读无需访客配置密钥。部分可选能力还需要独立安装、运行心潮和记忆服务。

## 🛠️ 页面打不开时

1. 确认启动终端仍在运行，并查看终端是否报错。
2. 运行根目录启动脚本，让它自动安装依赖、构建前端并启动两个服务；只打开 HTML 或只运行前端不够。
3. 使用 5173 端口时，同时保持 Vite 和后端运行。
4. `127.0.0.1` 仅指向当前电脑；其他设备无法用这个地址访问本机项目。
5. 端口被占用时检查占用进程。自带 `stop.cmd` 面向 8000、18110、18001，不负责关闭 5173 开发服务器。
