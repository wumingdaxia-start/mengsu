# 在其他电脑上使用花屿星

## 本机启动

安装 Python 3.10+ 与 Node.js LTS，解压项目后运行 `start.cmd`。
打开启动器显示的网站地址。不要直接双击 frontend/dist/index.html。
首次启动会安装依赖，需要联网。不要把个人 private/.env 或 data 目录打进分享包。

## AI 服务设置

从「我的空间 → AI 服务设置」，或睡前故事的「AI 服务设置」进入。
地址为 `/settings/ai`。填写自己的阿里云百炼 API Key，选择密钥所属地域，保存后分别测试文字和音色。
默认模型为 qwen-plus 和 qwen3-tts-flash；可根据账号实际开通的模型修改名称。
地域、模型权限、余额或服务商网络不可用时，测试会失败；网站不能代替服务商开通权限或提供免费额度。

个人配置用于梦境文字 AI、睡前故事与朗读，以及健康问答、习惯洞察和知识回答。
图片生成仍使用部署者单独配置的 IMAGE_API_KEY / IMAGE_BASE_URL / IMAGE_MODEL；本页面的千问密钥不会被发送给图片服务。
未配置时仍可阅读内置故事、播放本地氛围音乐、手动记录；保存个人记录需要登录且账号服务正常运行。

密钥只放在服务器进程内存中，最长 12 小时，浏览器仅保留 HttpOnly 随机会话 Cookie。
刷新页面可继续使用；到期、清除配置或重启服务后重新填写。配置按浏览器隔离，不覆盖服务器默认密钥。
文字和音色测试会调用服务商，可能产生少量费用。服务不保存或回显密钥。
个人配置目前面向单进程部署，多进程部署须增加共享加密凭据存储或会话粘性。

## 同一局域网

在项目目录运行 `.venv\Scripts\python.exe scripts\launch.py --host 0.0.0.0 --no-browser`。
其他设备访问 `http://运行电脑的局域网IP:8000/entry`。防火墙须允许该端口。
`127.0.0.1` 只代表使用者自己的电脑，不是可以发给其他人的网站链接。
账号与健康服务经 `/account-service/` 同站代理，无需开放 3001 端口。
局域网 HTTP 适合不含私人密钥的浏览；个人密钥应通过 HTTPS 或本机访问配置。

## 公网访问

需要一台持续运行的服务器、HTTPS 域名及反向代理。将网站请求统一代理到 8000 端口，保留 Host，并正确设置 X-Forwarded-Proto。
只信任自有反向代理提供的转发头，不直接开放 3001 端口。
不要公开携带个人历史记录的 data 目录。多人演示请分别注册账户，不共用公开演示账号记录敏感信息。
云端服务能否完整使用取决于部署、网络和服务商额度；增加设置入口不等于自动获得一个公网网站。
