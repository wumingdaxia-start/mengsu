# 花屿星心绪活动：独立内容版本说明

## 心绪行迹 v1

本版替换原 SBTI 测试：24 道重新编写的生活情境题、六条双极偏好轴和组合描述，不使用原问卷题库、图片、人物类型或匹配算法。每轴四题，其中两道反向题；五点选项先反向计分，再等权加总并线性映射为 0–100 的位置。0–37 为左侧，38–62 为中间区域，63–100 为右侧。组合名称取偏离中点最多的至多两条轴，名称只作回看描述。

这是项目自编的生活偏好探索，未经心理测量学验证，不是标准化人格量表。数字不是准确率、疾病风险或人群百分位。题目没有优劣答案。

## 星栈映照 v1

传统的 78 张塔罗牌名保留；六种生活反思牌阵、解释、提示、结果整理与抽取实现由本项目独立编写。使用系统随机源，无放回等概率抽取，正逆位各 50%，不使用提问、用户或时间加权，不提供预测、读心或诊断。

旧版 tarot-skill 抽牌脚本已由新实现替换；不再调用原脚本。旧 SBTI 文件及版权说明暂留作历史资源，新的测试入口不导入它们。历史结果保留原内容，不重新标记为原创。本说明不声称传统塔罗概念由本项目发明。

## 数据兼容

保留 personality / tarot 结果类别和现有账号保存链路；新版结果使用「心绪行迹」「星栈映照」前缀与 v1 版本说明，以便与历史结果区分。不得把既有第三方材料或历史结果的署名删除后冒充新内容。

## 原创人格卡牌

心绪行迹新增十二张独立绘制的 SVG 人物场景牌：听潮、围炉、守园、拾光、流云、织径、知温、辨星、泊岸、启帆、照叶、立灯。牌面以人物、日常物件和自然场景表达不同偏好，使用代码内矢量绘图，不依赖外部图片或旧版人格图鉴。无明显偏好时展示单独设计的「合流」牌。

结果卡牌按计分结果选择最明显的至多两种倾向，不作随机抽取；图鉴预览不会更改结果。卡牌名称、说明与测试结果一起进入既有保存链路，历史记录不改写。
